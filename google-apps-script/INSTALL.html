Arkham RPG Companion — Full Code สำหรับ Apps Script

ไฟล์นี้เป็นตัวช่วยคัดลอกโค้ดลง Google Apps Script ไม่ต้องติดตั้ง Node บน Mac แอปจริงเปิดผ่าน URL หลัง Deploy และบันทึกข้อมูลลง Google Sheets

  1. เปิด Google Apps Script และสร้าง New project
  2. แทนที่เนื้อหา Code.gs ด้วยโค้ด Code.gs ด้านล่าง แล้วสร้าง HTML ชื่อ Index, Styles, Client, Features ตามตัวเลือก (ไม่พิมพ์ .html ในช่องชื่อของ editor)
  3. Project Settings → เปิด Show appsscript.json manifest file in editor แล้ววาง appsscript.json
  4. ทำตาม README_TH.md ในโฟลเดอร์เดียวกัน: สร้าง Sheet ส่วนตัว, เปิด Sheets/Drive API, ตั้ง OAuth และ Script Properties, Deploy Web app
  5. Run initializeDatabase_, initializePrivateStorage_ และ checkInstallation_ จาก editor แล้วทดสอบ Login ด้วยสองบัญชี Google

อย่าวาง secret ในโค้ดหรือไฟล์นี้ ใช้ Project Settings → Script Properties เท่านั้น ดูผลทดสอบและขอบเขตการคำนวณอัตโนมัติใน README_TH.md

ถ้าปุ่มคัดลอกไม่ได้ ให้เลือกโค้ดทั้งหมดแล้วกด ⌘C จากนั้นวางใน Apps Script ด้วย ⌘V ไม่ต้องเปิดไฟล์ .gs ด้วยแอปบน Mac
